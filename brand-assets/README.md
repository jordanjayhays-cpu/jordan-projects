## Before using `acacia-lions-faces.jpg` as a logo or on anything public

**Provenance is unknown.** This looks like an existing stock or artist illustration, not an original
commission. Using it as a brand mark without a licence is a real legal risk, and a logo is the one
asset you cannot cheaply change later.

Two clean routes:
1. **Licence it** — find the source (reverse image search), buy the commercial/extended licence.
2. **Commission an original in this spirit** — brief a designer or generate a new mark using this only
   as a mood reference. The *idea* (negative-space profiles inside a tree) is not protectable; this
   specific execution is.

Do not put it on a live site, deck, or product until one of those is done.
