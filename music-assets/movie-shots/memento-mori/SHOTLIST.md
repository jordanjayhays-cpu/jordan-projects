# Memento Mori — mini movie shot list

30s preview, 10 shots at 3s each. Same Wanderer as The Cave (see `../CHARACTER.md`).

**Tonal note:** this is not The Cave's darkness-to-light descent. Memento Mori is
mortality-*aware* but life-affirming — "seize the day", "take a flight", "enjoy life
more". Keep the house teal palette and the same character, but the world is open, high
and moving: sky, wind, grass, birds. Almost no enclosure. That contrast is the point —
same man, opposite world.

## Build steps once the stills exist

```bash
# 1. save as shot01.png … shot10.png in this directory
# 2. trim the printed film border
python3 - <<'EOF'
from PIL import Image; import glob
for f in sorted(glob.glob("shot*.png")):
    im = Image.open(f).convert("RGB"); w, h = im.size; m = int(w * 0.055)
    im.crop((m, m, w - m, h - m)).save(f)
EOF
# 3. render + compress
python3 pipeline/movie_render.py <shots_dir> <memento-mori-preview.wav> \
        music-assets/memento-mori-lyrics.json memento-mori-minimovie.mp4
ffmpeg -y -i memento-mori-minimovie.mp4 -c:v libx264 -crf 24 -preset slow \
       -pix_fmt yuv420p -c:a aac -b:a 128k memento-mori-minimovie-web.mp4
```
