# Niah — Competitor Research

**Date:** July 15, 2026  
**Researcher:** Hermes  
**Status:** ✅ Complete

## Top Direct Competitors

### 1. Eventtia (eventtia.com)
- B2B matchmaking + networking platform
- Features: event registration, ticketing, check-in, event app, B2B matchmaking, Open API
- Has sponsors/exhibitors module (dedicated)
- Target: enterprise events, associations, conferences
- **Gaps:** no AI event ideas, attendee data insights appear basic

### 2. b2match (b2match.com)
- "Event platform built for networking" — most similar to Niah's stated direction
- Features: AI Matchmaking, Meeting Scheduler, Rich Profiles, Modular Agenda, Marketplace Messaging, Event Website Builder
- Pricing: ~$2/attendee
- **Gaps:** no AI-generated event ideas, sponsorship layer appears secondary

### 3. Bizzabo (bizzabo.com)
- Full Event Experience OS — enterprise tier
- Features: sponsorship management, lead capture, networking, marketing, analytics
- Very enterprise-heavy, expensive
- **Gaps:** complex/bloated for mid-market, no AI-native event ideation

### 4. vFairs
- Virtual/hybrid events focus, less networking-oriented

### 5. Cvent
- Enterprise-only, very expensive, legacy UX

### 6. Braindate
- Peer-to-peer knowledge networking at events — different angle

---

## White Space for Niah (Differentiated Opportunities)

1. **Attendee → Ideas → Sponsorship flow** — No competitor connects attendee data → AI event ideation → sponsorship monetization in one loop. Most do one or two of these.

2. **AI-native event ideas** — b2match has "AI Matchmaking" but no competitor generates AI-curated event concepts based on attendee profiles/interests.

3. **Mid-market pricing** — Bizzabo/Cvent are enterprise-only. b2match lacks the full funnel.

4. **Madrid/European market** — b2match and Eventtia both have EU presence but no clear winner in Madrid market.

---

## Bottom Line

Build the full funnel: **attendee data → AI event ideas → sponsorship insights**. That's the differentiated story. Don't compete on matchmaking alone — that's a feature, not a product.
