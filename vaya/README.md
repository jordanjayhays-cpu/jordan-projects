# Vaya — lives in its own repo

**Home: https://github.com/jordanjayhays-cpu/Vaya** (site, city pages, copy, project notes).

there) for movers, visitors, and investors. Manila is the live city; Mexico City and Bali next.
Domain: vayanews.com.

Do not file Vaya deliverables here. Put them in the Vaya repo. This folder exists only so the
project map is complete.
