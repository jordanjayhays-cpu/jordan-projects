## Rules applied (from Data Fluency notes)

| Rule | Source | What it means for this deck |
|---|---|---|
| Narrative arc: hook → rising action → climax → close | Ses. 7 | Keep the four parts. Slide 9 is the climax. |
| Hero = client, presenter = guide | Ses. 7 | IDB is the hero. Replace "we file" with "the region files". |
| Direct delivery = less text | Ses. 7 | Cut the italic aside wherever it adds a third idea. |
| Answer first ("Spoiler: 150 are fine") | Sugar deck, slide 2 | Add an executive summary up front. |
| Highlight palette: grey context, one colour for the point | Ses. 3 | Comparison countries go grey. Only the countries in the sentence get colour. |
| Gestalt similarity: same colour = same thing | Ses. 2 | Blue means Korea and orange means Mexico, so diagrams can't reuse them for "public" and "private". |
| Sort bars consistently | Ses. 3 | Slides 4 and 7 sort in opposite directions. Pick one. |
| Per capita, not totals, when sizes differ | Ses. 3 | Already done on slide 4. Keep it. |
| Max ~6 lines; end-of-line labels in the line's colour | Ses. 3 | Slides 6 and 10 already comply. |
| Never truncate when data touches the floor | Ses. 3 | All charts start at zero. Keep it. |
| Pictograms only for "1 in X" style comparisons | Ses. 3 | The dot unit changes every slide (1, 1,000, 20, 100). Keep the KEY box and say the unit aloud. Expect a Q&A question on it. |
| Show what the data can't tell you | Sugar deck, slide 16 | Move the "cannot tell us" box from the backup onto the closing slide. |
