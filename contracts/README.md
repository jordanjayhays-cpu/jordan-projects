# Contracts and expansion templates

Reusable templates from the IE "How to Expand Internationally" course, rebuilt as working tools
for helping family businesses enter a new country. Not legal advice.

| File | What it is | Live editable version |
| --- | --- | --- |
| `international-contract-template.md` | 8-section cross-border sale contract: Parties, Object, Transport, Payment, Guarantees, Courts, Legislation, Risks. Bracketed blanks, A/B clause options, drafting notes. | https://claude.ai/artifact/VNB9Jw2oZsLViseShxit7A |
| `international-market-analysis-template.md` | 11-question market analysis (market size, product, market) with a weighted go / no-go score, data-source list and a worked Mongolia example. | https://claude.ai/artifact/8ovsw8ZXh1CH31yqLQuVa2 |

Workflow: run the market analysis first; a "go" or "pilot" result feeds the contract template.
